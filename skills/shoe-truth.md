# Shoe Product Truth and Reference Evidence
Separate *visible observations* from user-supplied product descriptions and unknowns. Product reference photo is authoritative for actual geometry, toe profile, colors, logos, strap placement, sole silhouette, pair orientation. A single view never proves hidden outsole tread, comfort, durability, non-slip effect, material composition or sizing. Never invent text on shoe, branding, adornments, sidewalls or stitched details. If a needed angle is missing, choose a different physically supported shot. The truth lock is higher priority than aesthetics or user's marketing adjectives.
